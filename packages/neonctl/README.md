# neonctl

> **`neonctl` is now `neon`.** This package is a thin compatibility alias that forwards to the [`neon`](https://www.npmjs.com/package/neon) CLI. Install `neon` and use it directly.

```bash
npm i -g neon
```

The `neonctl` command keeps working — it prints a short notice and forwards to `neon` with the same arguments.
