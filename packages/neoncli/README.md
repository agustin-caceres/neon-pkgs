# neoncli

> **This is not the Neon CLI.** The Neon CLI is [`neon`](https://www.npmjs.com/package/neon). This package is a thin guard that forwards to `neon`.

```bash
npm i -g neon
```

If you ran `neoncli`, it prints a short notice and forwards to `neon` with the same arguments.
